Modelo de Utilizador - Alterações Propostas

Simplificação: usar apenas aldeiaId para todos os papéis

Modelo Atual

aldeiaId - Para papéis administrativos (vendedor, admin)

aldeiaPrincipalId - Para jogadores selecionarem aldeia para jogar

Complexo: dois campos semelhantes com propósitos diferentes

Modelo Proposto

apelidaId - Único campo de aldeia para TODOS os papéis

Exceto super_admin que pode ver todas as aldeias

Simplificado: um único campo para vincular utilizador a aldeia

Vantagens

  • Menos confusão - um único campo de aldeia
  • Consistente: todos os utilizadores pertencem a uma aldeia (exceto super_admin)
  • Mais fácil de manter e entender
  • Evita inconsistências entre aldeiaId e aldeiaPrincipalId

Desvantagens

  • Requer migração de dados existentes
  • Precisa atualizar todas as referências ao código
  • aldeiaPrincipalId será removido completamente
